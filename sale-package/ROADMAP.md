# Suggested Roadmap

This roadmap is scoped for a buyer who wants to move CyberReady from transfer-ready prototype to commercial product.

## Phase 1: Acquisition Cleanup

- Confirm IP transfer terms.
- Confirm domain transfer details.
- Review third-party reference material rights.
- Rotate all demo credentials for hosted demos.
- Capture screenshots and short demo videos.
- Add CI for builds and smoke tests.

## Phase 2: Production Hardening

- Migrate Hall Monitor from SQLite to Postgres.
- Add managed session storage.
- Move uploads to object storage.
- Add environment-specific configuration validation.
- Add monitoring, logging, and error tracking.
- Add backup and restore procedures.
- Add security headers and deployment hardening.

## Phase 3: Product Readiness

- Add buyer or operator onboarding templates.
- Add district provisioning and role invitation workflow.
- Add formal assessment report export formats.
- Add evidence management improvements.
- Add audit trail filtering and export.
- Add configurable scoring profiles.
- Add stronger CAIRE evidence validation workflows.

## Phase 4: Commercial Launch

- Add pricing and packaging pages.
- Add CRM integration or lead routing.
- Add controlled acquisition demo mode.
- Add operator success playbooks.
- Add buyer onboarding checklist inside Hall Monitor.
- Build repeatable CCRE and CAIRE workflows that can support consulting, SaaS, or managed-service delivery models.

## Phase 5: Platform Expansion

- Add SSO and MFA.
- Add insurance carrier reporting templates.
- Add state-specific compliance packs.
- Add AI vendor inventory and DPA workflow.
- Add recurring reassessment scheduling.
- Add trend analysis across assessment periods.
