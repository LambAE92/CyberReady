# Suggested Roadmap

This roadmap is scoped for a buyer that elects to evolve CyberReady from an acquisition-ready prototype to a commercial product. It is not represented as implemented functionality.

## Phase 1: Transaction and Packaging Decisions

- Confirm source, methodology, brand, media, domain, and account transfer scope.
- Decide the disposition of NIST AI RMF Playbook content and retained legacy CCRE/Cybersecurity Rubric materials.
- Confirm synthetic-demo labels and capture only approved screenshots/videos.
- Build the controlled buyer data room and buyer-specific demo process.
- Generate an SBOM/NOTICE and run clean-install advisory/secret checks in the buyer environment.

## Phase 2: Production Hardening

- Migrate Hall Monitor from SQLite to Postgres with versioned migrations.
- Add managed session storage, enterprise identity, and tenant provisioning.
- Move evidence/uploads to encrypted object storage with scanning and lifecycle controls.
- Add environment-specific configuration validation, CI/CD, monitoring, logging, and error tracking.
- Add backup, restore, and incident-runbook procedures.

## Phase 3: Product Readiness

- Add buyer-selected onboarding and operator workflows.
- Add downloadable CCRR report formats and stronger evidence management.
- Add recurring reassessment scheduling, longitudinal trends, audit-trail export, and configurable scoring only where product fit warrants it.
- Define the future role of externally sourced AI RMF guidance after the owner/counsel decision.

## Phase 4: Commercial Launch

- Add buyer-approved pricing, lead routing, CRM, and consent workflows.
- Build a controlled acquisition/demo mode.
- Create operator-success playbooks.
- Build repeatable CCRR/CEAM and CAIRE/CAGR delivery workflows after their provenance decisions are complete.

## Phase 5: Platform Expansion

- Add SSO/MFA and broader role/tenant controls.
- Add buyer-selected insurance, state-compliance, AI-vendor inventory, and integration workflows.
- Add buyer-defined telemetry or ticketing/GRC integrations only if commercially justified.
